# 《星恸 · 餐厅日记》（Star Mourn: Canteen Log）游戏策划案

> 本文档为《星恸》IP 下的衍生模拟经营游戏《餐厅日记》的完整策划案。
> 所有种族、阵营、天体与代谢理论均严格沿用《星恸》世界观基础设定集，
> 可作为独立项目快速落地的统一基准。

---

## 一、项目概述

| 项 | 内容 |
| :--- | :--- |
| 项目名称 | 星恸 · 餐厅日记（暂定）/ Star Mourn: Canteen Log |
| 所属 IP | 《星恸》（Star Mourn）宇宙 |
| 品类 | 星际模拟经营 + 流水线建造 + 顾客接待叙事 |
| 视角 | 2.5D 剖面视角（类似《星露谷物语》俯视 + 《边缘世界》剖面基底感） |
| 平台 | PC / 移动端 / H5（基于 Cocos 引擎，见 `restaurant-diary` 工程） |
| 核心体验 | 在乱纪元的星际空间站里，经营一家为「所有种族」提供补给的餐厅 |
| 一句话定位 | **"无论碳基、硅基还是液金，你都能在这里吃饱、充能、拿到数据。"** |

### 设计原点（Why）
《星恸》设定中，自然生命仅 30%，人造/合成生命高达 70%，且所有生命由 **1~2 个代谢因子**定义。
这意味着「吃饭」对不同种族是完全不同的概念：人类吃有机质，泰拉吃矿物，水晶吸电流，哔啦泡流体。
《餐厅日记》把这一底层设定转化为核心玩法——**餐厅本质是一座「跨种族补给中枢」**，菜单即补给清单。

## 二、世界观定位（如何嵌入《星恸》）

### 2.1 时空坐标
- **纪元**：西塔θ乱纪元第 16 年（三大阵营并立、补给断裂、信标衰弱、黑市崛起）。
- **坐标**：边境自治走廊 × 商贸自由港联区交界处的「赫尔墨斯大自由港」外缘，
  一座环港 **巨构补给空间站（Citadel Station）**——官方设定中"具备完备人工重力与维生系统、提供物资流转/飞船修整补给/情报交互"的标准空间场景。
- **合理性**：在乱纪元，跨星域航线瘫痪、各星区物资割据。一座自由港边缘的补给站，
  天然成为流窜商队、难民、探险者与走私客的"最后能喘口气的地方"。

### 2.2 玩家角色
玩家是餐厅的 **「店长（Manager）」**——一位继承自旧联邦补给站体系的 **人类（碳基+水机）** 经营者，
或自定义出身（可在创建时选择自身代谢因子，影响初始可吃/可补给的品类）。
玩家并非战士，而是**乱纪元秩序缝隙里的「补给节点」**。

### 2.3 与三大阵营的关联
| 阵营 | 与餐厅的关系 | 互动带来的玩法 |
| :--- | :--- | :--- |
| **复统派** | 视餐厅为"可规训的补给据点"，愿发航道通行证 | 提供稳定客流与规范补给，但要求上报顾客情报 |
| **扩张派** | 视餐厅为"资源采集前哨"，想强征 | 高压事件：拒绝供应会被断供，妥协则获重工设备 |
| **自保派** | 最友善的贸易伙伴，等价交换 | 解锁稀有食材/配方、中立庇护 |

## 三、核心设定

### 3.1 餐厅 = 跨种族补给中枢（三大补给线）

餐厅不只卖"饭"，而是同时为顾客提供三类补给，对应设定中空间站的三大功能：

1. **食物 / 营养补给（Nutrition）**：按代谢因子定制的"餐品"。
2. **数据库 / 情报补给（Data）**：设定中"情报交互"功能的落地——顾客可查询星图残片、信标坐标、失联亲人记录。
3. **电源 / 能量补给（Power）**：设定中"飞船修整补给"的微型化——为机械/电气/气能系顾客直接充能。

> **巧思**：一条顾客的需求常同时跨越两类补给。例如「拓境智能（电气+机械）」既要充能（电源），又要下载星图（数据库），还要上润滑油（食物线里的"机械因子补给"）。

### 3.2 代谢因子 × 供应品类映射（核心玩法基石）

严格沿用设定的 9 大代谢因子，将其映射为 9 条「补给品类线」：

| 因子 | 代谢因子 | 餐厅对应「供应品类」 | 顾客吃/用它做什么 |
| :--- | :--- | :--- | :--- |
| 01 | 碳基因子 | 有机质餐 / 蛋白质块 | 碳基生命的"正餐" |
| 02 | 水机因子 | 流体 / 纯水 / 溶剂 | 体液补给、排热解毒 |
| 03 | 生化因子 | 真菌培养体 / 共生软体 / 克隆组织 | 自愈、增殖、生态循环 |
| 04 | 矿质因子 | 矿石粉 / 合金骨板 / 矿物盐 | 甲壳与无机骨骼生长 |
| 05 | 硅基因子 | 晶体 / 半导体脉络 | 晶格稳定、神经传导 |
| 06 | 气能因子 | 等离子 / 气态工质 | 热核循环、离子激发 |
| 07 | 机械因子 | 构件 / 润滑油 / 自修补件 | 传动、耐磨、结构 |
| 08 | 电气因子 | 电流 / 能量块 / 稳压回路 | 逻辑运作、感测 |
| 09 | 液金因子 | 液态金属 / 记忆合金浆 | 形变、密封、重组 |

**设计推论**：每个顾客的种族由 1~2 个因子组成 → 每个顾客有 **1~2 条专属补给需求**。
玩家必须**同时备齐对应品类的流水线**，才能满足该顾客。这是所有玩法的总开关。

### 3.3 空间站的餐厅结构（场景分区）
- **前厅（Front Hall）**：接待台、等位区、情报终端（数据库线）、充能桩（电源线）。
- **后厨流水线区（Kitchen Line）**：玩家搭建的食物流水线，9 条品类线各自独立又可在「合成站」交汇。
- **仓储与温室（Store & Greenhouse）**：原料仓、活体培养舱（生化因子原料）、晶体生长室（硅基原料）。
- **员工宿舍（Crew Quarters）**：招牌员工休息与升级区。
- **泊位平台（Berth）**：顾客飞船停靠，决定其可停留时长（限时服务压力）。

## 四、核心玩法

### 4.1 顾客接待循环（单局核心 Loop）
```
顾客飞船泊位 → 接待台登记（读取种族/代谢因子/需求） → 
分配前厅服务（食物/数据库/电源） → 后厨流水线产出补给 → 
交付结算（货币/情报/声望） → 顾客离港、留下评价与故事碎片
```

- **限时压力**：每位顾客的飞船泊位有倒计时。超时未交付则流失，并影响该种族的「好感/声望」。
- **多需求并发**：同一时段多艘船泊位，玩家需用「流水线并行」+「招牌员工调度」应对。
- **日记叙事**：每次成功接待自动生成一条「餐厅日记」条目，记录顾客种族、故事、留下的物品/情报。日记是叙事载体（呼应游戏名）。

### 4.2 食物流水线系统（招牌玩法）

这是本作区别于普通经营游戏的核心：玩家**像工厂游戏一样搭建补给产线**。

#### 流水线构成
```
[原料采集/进货] → [预处理站] → [加工站(按因子)] → [合成站] → [出餐/充能/数据封装] → [前厅交付]
```

- **9 条品类干线**：每条对应一个代谢因子，由「加工站」类型决定（如「矿物研磨站」=矿质线，「等离子激发器」=气能线）。
- **合成站（交汇点）**：当某顾客需要 2 个因子（如 碳基+水机 = 人类），需将两条干线在合成站汇流，产出复合补给。
- **模块化升级**：玩家用经营收益购买/研发更高级的加工站模块（提升速率、降低损耗、解锁新配方）。

#### 流水线策略维度
| 维度 | 说明 |
| :--- | :--- |
| 速率 | 加工站等级决定单位时间产出 |
| 损耗 | 跨因子合成有损耗率，需「维稳模块」降低 |
| 并行度 | 招牌员工可同时值守多条线 |
| 自动化 | 后期解锁「枢纽蜂工」集群自动巡线 |

#### 示例：做一份「人类套餐」
> 碳基因子(有机质餐) + 水机因子(纯水) → 合成站汇流 → 「标准人类营养餐」 → 交付人类/遗落之子/森裔/鳞羽翼客（均为含碳基或水机的种族）。

### 4.3 数据库系统（情报补给线）

承接设定中「情报交互」与「信标衰弱」：
- 顾客可在前厅**查询/上传数据**：星图残片、失联亲人坐标、旧联邦档案。
- 玩家经营「数据库终端」，积累的数据可：
  - **解锁新配方**（从古文明遗迹数据里解析出稀有补给工艺）。
  - **兑换航线**（向复统派换航道通行证，向自保派换庇护）。
  - **触发事件**（某顾客查询到亲人已在西塔 4 年物资危机中遇难 → 触发支线叙事）。

### 4.4 电源/能量系统（充能补给线）

- 前厅设「充能桩」，为机械/电气/气能系顾客直接供能。
- 餐厅自身也消耗能量维持维生系统；能量来自：
  - 售卖结余的「能量块」、
  - 「水晶」「烁光灵」等充能型顾客的反向馈赠、
  - 后期自建「地热/聚变反应堆」（呼应岩浆行星地热设定）。
- **能源危机事件**：扩张派强征时切断外部供电，玩家须靠自给能源硬撑。

## 五、招牌员工系统（Signature Crew）

将《星恸》的 **23 类种族/合成生命**转化为「招牌员工」，每位员工基于其代谢因子，拥有专属厨房/运营技能。
聘用不同种族 = 自动获得对应因子线的专家。

### 5.1 员工技能逻辑
员工的**代谢因子**决定其"天生擅长哪条补给线"；其**种族特性**决定特殊被动。

### 5.2 招牌员工图鉴（示例，可从基础设定 23 种族中选取/扩展）

| 员工（种族） | 代谢因子 | 招牌技能 | 在餐厅的作用 |
| :--- | :--- | :--- | :--- |
| **哔啦 Bila** | 水机+生化 | 半流体身躯，可挤入任何缝隙 | 清洗/输送/狭窄管道维修；水机线高效处理 |
| **泰拉 Terra** | 硅基+矿质 | 力大无穷、无视高低温真空 | 矿石粗碎、重料搬运；矿质线零损耗 |
| **水晶 Crystal** | 硅基+电气 | 操控电磁波与能量 | 充能桩主控、电气线稳压；可被"食用"反向供电 |
| **巢蛹 Hive Chrysalis** | 碳基+生化 | 有机质转化、蜂巢心智 | 活体食材培育、生化线高产；多任务并行 |
| **拓境智能 Frontier AI** | 电气+机械 | 数据协同、星图测绘 | 数据库终端管理、自动排单；机械线诊断 |
| **液态构装 Liquid Construct** | 液金+电气 | 任意形变工具 | 临时充当任意加工站配件；应急密封补漏 |
| **烁光灵 Spark Spirit** | 气能+电气 | 穿行电磁场 | 气能线激发、线路巡检；危机时充当应急光源 |
| **仿生织者 Bionic Weaver** | 生化+电气 | 高精度微操 | 精密合成、复合补给零损耗；疗愈同事 |
| **枢纽蜂工 Hub Drone（群）** | 机械+电气 | 集群流水线协同 | 自动值守多条干线，规模化产出 |
| **虚数幽灵 Imaginary Phantom** | 电气 | 数据入侵/加密 | 黑市数据嗅探、解锁隐藏配方（灰色手段） |

> **成长**：员工有等级/好感。好感提升解锁「专属菜谱/补给工艺」，并可能引出该种族的个人支线（如泰拉怀念母星矿脉）。

### 5.3 员工调度
- 同时段可上阵 N 名招牌员工（随餐厅等级扩张）。
- 员工可被指派到具体流水线/前厅岗位，触发组合技（如「水晶+烁光灵」= 充能效率翻倍）。

## 七、经营与成长系统

### 7.1 三重货币 / 资源
| 资源 | 来源 | 用途 |
| :--- | :--- | :--- |
| **星币（Credits）** | 顾客结算 | 扩建、买设备、进货 |
| **情报（Intel）** | 数据库线/顾客故事 | 解锁配方、换航线、推进剧情 |
| **声望（Reputation）** | 各族好评 | 提升某种族客流、解锁阵营合作 |

### 7.2 成长主轴
1. **空间扩建**：泊位↑ → 前厅工位↑ → 流水线槽位↑ → 员工宿舍↑。
2. **产线研发**：从单因子粗加工 → 多因子精密合成 → 全自动蜂工集群。
3. **种族声望**：喂饱足够多的某种族，该种族在自由港建立「常驻使团」，带来稳定订单。
4. **阵营关系**：在三大阵营间周旋，选择「中立补给者」或「某派御用据点」走向不同结局。

### 7.3 事件系统（乱纪元特色）
- **补给断裂**：某原料因星区割据断供，须临时替换配方（用其他因子近似替代，影响满意度）。
- **海盗临检**：暗影掠夺同盟登站"收税"，可选付费/拒付（触发防卫事件，可雇防卫型员工）。
- **难民潮**：人道救援战线送来大批濒危自然种族，限时公益供给，奖励声望。
- **信标异动**：旧联邦信标短暂复苏，大量迷失飞船涌入，爆单高峰。

## 八、叙事与日记系统（情感内核）

呼应游戏名《餐厅日记》：
- 每位顾客离港后生成一条**日记**，含其种族、外貌简绘、点单、对话片段、留下的物品/情报。
- 日记累积成「星港众生相」，逐步拼出乱纪元下各文明的真实生存图景。
- **主线暗线**：玩家逐渐发现，这座补给站前身是旧联邦「始源门」补给节点，藏着大断连真相的一角——呼应设定中"中央直辖核心圈权力真空、谁继承第四联邦法统"的宏观悬念。

## 九、美术与氛围

- **整体风格**：暖色温润的「赛博暖炉」——在冰冷乱纪元的太空里，餐厅是唯一有光与饭香的地方。
- **种族呈现**：严格按基础设定视觉特征（碳基拟人、硅基晶体、液金流动、电浆光团），差异化极强，天然适合"百家齐聚一厅"的视觉奇观。
- **流水线可视化**：透明管道+发光流体，不同因子用不同光色（碳基绿、硅基蓝、气能紫、液金银……），一眼可辨产线状态。
