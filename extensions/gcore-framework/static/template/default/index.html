字体工具

提供全面的字体处理能力，包括多语言缺字检测、文本抽字子集化压缩以及 TTF/OTF/WOFF2 格式互转。

1. 字体缺字检测工具

选择目标字体文件并指定某种多语言，工具将解析字体支持的完整字符映射表，与该语言下所有文本条目进行全量比对，精确检测是否存在字体缺少字符（缺字/字形缺失）的情况。

2. 字体抽字压缩工具 (子集化)

从源字体文件中仅抽取出指定参考文本文件（如 .txt、.json、.csv 等）中包含的字符，精简剥离多余字形，极大程度减小字体文件体积（压缩率可达 90%~99%）。点击导出时将弹出系统窗口选择保存位置与文件名。

3. 字体格式互转工具 (.ttf / .otf)

提供 .ttf 与 .otf 字体格式之间的高性能无损相互转换。点击转换时将弹出系统窗口选择保存位置与文件名。

4. 预制体/场景字体批量替换工具

选中字体资源文件，直接修改预制体 (.prefab) 与场景 (.scene) 文件结构，将所有 Label 与 RichText 文本组件字体批量替换为目标字体。

1. .meta 文件清理工具

针对 Cocos Creator 3.8 删除或重命名文件/文件夹后可能残留无效 .meta 文件的 Bug。选择目标目录，自动扫描并清理找不到对应文件/文件夹的残留 .meta 文件。
