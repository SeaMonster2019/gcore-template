# GCore 音频模块使用说明 (Audio Module)

`gcoreAudio` 是 GCore 框架提供的音频管理系统，专为 Cocos Creator 3.8+ 设计，旨在让业务层**极简调用、零心智负担、无音频资源泄露**。

---

## 一、 核心特性

- **零心智负担**：业务层无需手动创建 `AudioSource` 节点、无需管理播放实例回收与引用计数释放。
- **BGM 平滑淡入淡出 (CrossFade)**：双轨无缝过渡切换背景音乐，告别生硬突变。
- **BGM 历史栈 (push/pop)**：支持进入战斗/副玩法临时插播 BGM，退出后自动出栈平滑恢复原曲目。
- **音效对象池与防爆音节流**：
  - 动态 `AudioSource` 对象池与自动垃圾回收。
  - 同一音效默认 50ms 防连击节流与同名最大并发数限制，避免集群怪音效卡顿或爆音。
- **系统切后台自适应**：监听 `game.EVENT_HIDE` / `game.EVENT_SHOW`，切后台自动暂停，切回前台自动恢复。
- **存储解耦**：框架专注于运行时音量计算与控制，提供 `setConfig` / `getConfig` 便于业务层无缝对接自己的存档系统。
- **快捷组件**：提供 `AudioButton` 组件，挂载即可实现点击音效，业务代码零侵入。

---

## 二、 引入方式

在业务代码中直接通过模块别名引入：

```typescript
import { gcoreAudio } from "gcore-framework/audio";
```

> **提示**：框架入口组件 `GCoreInit` 挂载运行后会自动完成 `gcoreAudio.init()`，业务层无需手动执行初始化。

## 三、 背景音乐 (BGM) 使用

### 1. 播放背景音乐
支持直接传入资源路径（基于 `gcoreRes` 自动加载与引用管理）或传入 `AudioClip` 实例。

```typescript
// 基础播放（默认 fadeDuration = 0.8s，平滑淡入淡出）
gcoreAudio.playMusic("audio/bgm_lobby");

// 自定义选项播放
gcoreAudio.playMusic("audio/bgm_lobby", {
    bundle: "resources",    // 资源包名称，默认为 "resources"
    loop: true,             // 是否循环播放，默认为 true
    volume: 0.8,            // 该曲目的相对音量比例 (0.0 ~ 1.0)，默认为 1.0
    fadeDuration: 1.5,      // 淡入淡出过渡时长（秒），设为 0 表示即时切换
});
```

### 2. 临时插播与恢复（音乐栈）
适合场景：常驻主城音乐 → 触发 Boss 战临时切歌 → 战斗结束平滑切回原音乐。

```typescript
// 1. 临时压入并播放 Boss 战 BGM（框架会自动将当前曲目现场保存在栈中）
gcoreAudio.pushMusic("audio/bgm_boss", { fadeDuration: 1.0 });

// 2. 战斗结束后，弹出并自动恢复上一首背景音乐
gcoreAudio.popMusic(1.0);
```

### 3. 停止 / 暂停 / 恢复
```typescript
// 平滑淡出并停止（默认淡出时长 0.5s）
gcoreAudio.stopMusic(0.5);

// 暂停与恢复播放
gcoreAudio.pauseMusic();
gcoreAudio.resumeMusic();

// 状态查询
const isPlaying = gcoreAudio.isMusicPlaying();
const curPath = gcoreAudio.getCurrentMusicPath();
```

## 四、 音效 (SFX) 使用

### 1. 基础播放
播放完毕后框架会自动触发 `AudioSource.EventType.ENDED` 回收到对象池，并自动管理 `gcoreRes` 的资源引用。

```typescript
// 普通触发
gcoreAudio.playEffect("audio/click");

// 携带选项播放
gcoreAudio.playEffect("audio/explosion", {
    bundle: "resources",
    volume: 1.0,
    throttleMs: 50,         // 防爆音节流时间（毫秒），同一音效在此间隔内重复调用将被忽略
    onComplete: () => {
        console.log("音效播放完毕");
    }
});
```

### 2. 长音效句柄控制 (AudioId)
针对需要持续循环并在特定时机停止的音效（如技能蓄力声、警报声、激光持续声）：

```typescript
// 播放循环音效并获取 audioId
const laserAudioId = await gcoreAudio.playEffect("audio/laser_loop", { loop: true, volume: 0.7 });

// 动态调整该特定音效的独立音量
gcoreAudio.setEffectInstanceVolume(laserAudioId, 0.3);

// 停止该特定音效
gcoreAudio.stopEffect(laserAudioId);
```

### 3. 全局音效控制
```typescript
// 停止所有正在播放的音效
gcoreAudio.stopAllEffects();

// 暂停与恢复所有音效
gcoreAudio.pauseAllEffects();
gcoreAudio.resumeAllEffects();
```

## 五、 音量与静音控制

支持三层级音量：`最终输出音量 = 主音量 * 分组音量 * 实例相对音量`。

### 1. 单项设置与查询
```typescript
// 设置音量 (0.0 ~ 1.0)
gcoreAudio.setMasterVolume(1.0);  // 全局主音量
gcoreAudio.setMusicVolume(0.7);   // 背景音乐音量
gcoreAudio.setEffectVolume(0.9);  // 音效应量

// 获取当前音量
const masterVol = gcoreAudio.getMasterVolume();
const musicVol = gcoreAudio.getMusicVolume();
const effectVol = gcoreAudio.getEffectVolume();

// 设置静音开关
gcoreAudio.setMasterMute(false); // 全局主静音
gcoreAudio.setMusicMute(true);   // 静音背景音乐
gcoreAudio.setEffectMute(false); // 静音音效

// 获取静音状态
const isMasterMuted = gcoreAudio.isMasterMuted();
const isMusicMuted = gcoreAudio.isMusicMuted();
const isEffectMuted = gcoreAudio.isEffectMuted();
```

### 2. 批量配置与业务存档同步
```typescript
// 1. 获取完整配置快照保存到业务存档
const audioConfig = gcoreAudio.getConfig();
mySaveSystem.save("user_audio_setting", audioConfig);

// 2. 游戏启动后，从业务存档批量恢复配置给框架
const savedConfig = mySaveSystem.load("user_audio_setting");
if (savedConfig) {
    gcoreAudio.setConfig(savedConfig);
}
```

### 3. 全局一键暂停 / 恢复
常用于打开全屏暂停菜单、剧情黑屏切场时：

```typescript
// 同时暂停背景音乐与所有音效
gcoreAudio.pauseAll();

// 同时恢复背景音乐与所有音效
gcoreAudio.resumeAll();
```

## 六、 辅助组件：AudioButton

框架提供了零代码的按钮点击音效组件 `AudioButton`。

### 使用步骤：
1. 选中任意带有 `cc.Button` 的 UI 节点。
2. 在属性检查器中添加组件：`GCore/Audio/AudioButton`。
3. 配置属性：
   - **音效路径 (soundPath)**：如 `audio/click`。
   - **资源包 (bundle)**：默认为 `resources`。
   - **直接指定Clip (soundClip)**：可选，优先于路径。
   - **音量比例 (volume)**：滑块调节点击音量 (0.0 ~ 1.0)。

## 七、 API 完整速查表

| 方法 | 说明 | 返回值 |
| :--- | :--- | :--- |
| `playMusic(source, options?)` | 播放背景音乐（支持平滑淡入淡出） | `Promise<boolean>` |
| `pushMusic(source, options?)` | 压入并播放临时背景音乐（进入音乐栈） | `Promise<boolean>` |
| `popMusic(fadeDuration?)` | 弹出并恢复上一次压入的背景音乐 | `Promise<boolean>` |
| `stopMusic(fadeDuration?)` | 停止当前背景音乐 | `void` |
| `pauseMusic()` | 暂停背景音乐 | `void` |
| `resumeMusic()` | 恢复背景音乐 | `void` |
| `isMusicPlaying()` | 查询背景音乐是否正在播放 | `boolean` |
| `getCurrentMusicPath()` | 获取当前播放的背景音乐资源路径 | `string` |
| `playEffect(source, options?)` | 播放音效（自带防爆音节流与自动回收） | `Promise<number>` (audioId) |
| `stopEffect(audioId)` | 停止指定句柄的音效 | `void` |
| `stopAllEffects()` | 停止所有正在播放的音效 | `void` |
| `setEffectInstanceVolume(audioId, vol)` | 动态调节特定音效实例的相对音量 | `void` |
| `pauseAllEffects()` | 暂停所有音效 | `void` |
| `resumeAllEffects()` | 恢复所有音效 | `void` |
| `setMasterVolume(volume)` | 设置全局主音量 (0.0 ~ 1.0) | `void` |
| `getMasterVolume()` | 获取全局主音量 | `number` |
| `setMasterMute(mute)` | 设置全局主静音 | `void` |
| `isMasterMuted()` | 获取全局主静音状态 | `boolean` |
| `setMusicVolume(volume)` | 设置背景音乐音量 (0.0 ~ 1.0) | `void` |
| `getMusicVolume()` | 获取背景音乐音量 | `number` |
| `setMusicMute(mute)` | 设置背景音乐静音 | `void` |
| `isMusicMuted()` | 获取背景音乐静音状态 | `boolean` |
| `setEffectVolume(volume)` | 设置音效应量 (0.0 ~ 1.0) | `void` |
| `getEffectVolume()` | 获取音效应量 | `number` |
| `setEffectMute(mute)` | 设置音效应量静音 | `void` |
| `isEffectMuted()` | 获取音效应量静音状态 | `boolean` |
| `setConfig(config)` | 批量设置音频配置 | `void` |
| `getConfig()` | 获取完整音频配置快照 | `IAudioConfigData` |
| `pauseAll()` | 同时暂停背景音乐与所有音效 | `void` |
| `resumeAll()` | 同时恢复背景音乐与所有音效 | `void` |
| `getHostNode()` | 获取挂载音频组件的宿主节点 | `Node \| null` |
| `destroy()` | 销毁并清理音频管理器与事件监听 | `void` |
